# 自进化与消融实验

自进化比较初始策略及四轮更新后的策略，共五个检查点。各策略在同一独立患者集上评价，固定模型、探索指导、初始方向配比、采样种子、任务上限及公共评价。评测结果不回流到更新侧。进化患者按四轮划分；现有两轮运行不能作为完整四轮实验结果。

图采用三个横向面板：四维质量均值（1–5 分，四条线）、核验通过率（0–100%）、高阶有效题数。横轴为 0–4 轮，0 表示初始策略。点和误差线表示估计量及患者簇 95% bootstrap 区间，缺失检查点保留间断。计数面板的上限依据实际请求题数确定。当前模板不产生数据点或趋势线。

消融包括完整模型、去数据探索、去环境探索和关闭反馈更新。独立评测患者、模型、预算及公共评价一致。结果表报告核验通过题数、四维质量、高阶有效题数和生成 token。探索、更新和方法内部生成均纳入成本，公共评价另列。

输出：英文 PDF、SVG、PNG 图，机器可读的五检查点空白数据模板；论文新增策略自进化和组件消融两节。科研绘图采用项目 scientific-visualization 技能，以现有实验图字体及主图青蓝、橙色为基础。

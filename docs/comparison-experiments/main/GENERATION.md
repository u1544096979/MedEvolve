# 主方法生成输入与答案约束

## 生成输入

每个患者一次 LLM 调用，同时生成题目、候选参考答案与证据。轨迹正文保留时间顺序，来源列表保留 source_id 与原始记录的直接对应。生成输入仅包含本批指定方向与策略的 generation_guidance；题型数量按指定方向限制。

## 答案约束

事实查询答案给出记录支持的数值、单位与时间。每条证据声明只包含当前引用实际支持的事实，日期使用临床事件字段，不使用资源更新时间。跨记录结论逐条引用依据。

临床判断区分患者事实与临床推断，说明判断依据与材料限制；不把活动处方解释为疗效良好，不推断未记录的耐受性。候选参考答案回应明确的题目要求，并允许合理等价方案。

## 小样本验证

使用真实缓存患者轨迹与既有公共核验；保留生成请求、候选答案、引用原记录与拒绝原因。核对正确引用、错误引用、指定题型和合理等价答案的处理。

## 两轮实际结果

两轮策略反馈与更新保留初始探索指导，独立评测患者不参与策略学习。报告实际产出、核验、解题、运行故障与用量；原始记录作为事实依据。

# Workflow 方法对比规范

## 定义

Workflow 为本实验的“固定阶段生成”方向对比，按本文件定义实现，不对应某篇已确认的论文，也不以论文复现名义报告。没有 MedEvolve 特有的数据探索和跨轮进化。

## 流程

固定执行三个阶段：定位、生成、内部检查。定位一次调用依据轨迹和给定方向，选定两个临床关注点与相关 source_id；题型由公共方向指定。生成一次调用据此输出 TaskBatch。内部检查一次调用逐题判断清晰度、题意与候选答案对应、引用是否支持声明，筛除不通过候选。阶段不回退、不自主重新规划、不跨患者学习。

## 答案与证据

生成阶段给出候选参考答案；内部检查只保留或拒绝，不改写答案。内部检查结果不等于公共评测通过。方法仅使用输入轨迹，不自行访问环境。

## 输入输出

遵循 [公共规范](../../common/SPEC.md) 的 generate_tasks。directions 指定两个目标方向，输出 TaskBatch 最多两题；每题包含 instruction、task_type、reference_answer、evidence 和 decision_point，首轮 decision_point 为 null。患者、环境、方法和任务编号由公共入口附加。

公共输出约束、题型定义与评测提示词一致；方法内部提示词体现上述方向区别。运行状态及成本必须包含全部内部调用，不能只保留最后一份模型结果。

## 文件边界

实现位于 methods/workflow/。不修改其他方法、公共评测或患者划分。复用标准运行层，不创建自己的 LLM 客户端或 Agent 循环。

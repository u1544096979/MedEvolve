## 实验 1：任务生成与推理深度

### 1.1 要回答的问题

### 1.2 设置（已定）
- 环境：PhysicianBench（已有）；MedAgentBench（待补，见 1.6）。
- 划分：每个环境按患者分为进化集与测试集，约 25% / 75%，种子 42。
  - PhysicianBench：27 / 81；MedAgentBench：25 / 75。
- 进化集只供 MedEvolve 更新策略；基线不进化，直接在测试集上生成。
- 所有方法统一两轮，每位患者最多请求 2 题。PhysicianBench 共 162 题，MedAgentBench 共 150 题。

## 实验 2：合成任务补充官方训练

### 2.1 要回答的问题
MedEvolve 生成的合成题，能否作为官方训练数据的有效补充，且收益来自任务质量而非题数？

### 2.2 设置
- 模型：Qwen3.8-27B（量化，关闭 thinking）。
- 框架：ACE、Reflexion、OpenClaw。主框架 **待选**（建议 Reflexion 或 OpenClaw，把 A 到 D 做完整；另一框架做 A、B、C）。
- 测试集：50 道官方题。
- 训练题：官方 20 题固定；合成题只从通过核验的题中按固定种子抽取。

### 2.3 四组对比
| 组 | 训练内容 | 回答的问题 |
|---|---|---|
| A | 零经验（不训练） | 所有组的起点 |
| B | 官方 20 | 基础数据 |
| C | 官方 20 加 MedEvolve 合成 20 | 我们的方法 |
| D | 官方 20 加 TaskCraft 合成 20 | 换生成器的对照 |

对比读法：
- C 对 B：合成题能否补充官方数据。
- C 对 D：收益是否来自任务质量（C 与 D 题数、种子、训练顺序一致）。
- 官方 40（E）不在本版，有空再补，补上后才能写“接近真题”。

### 2.4 必须控制的变量
- C、D 的合成题数同为 20，训练顺序与种子一致。
- 同一测试集、同一模型、同一框架设置。
- D 使用实验 1 中 TaskCraft 已通过核验的题，不重新生成。
- 合成训练题所用患者与 50 道测试题患者分开，至少报告重叠比例。
- 在附录报告 C 与 D 各自的 L1 到 L4 构成（难度不做人为对齐，它正是差异所在）。
- 每组至少 3 个种子，报告均值与区间；同题配对比较。
- 基础设施出错的运行重跑，或事先写明排除规则。

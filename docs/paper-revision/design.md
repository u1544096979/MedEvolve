# MedEvolve 中文论文结构

## 稿件范围

目标为 NAACL 方法论文。中文正文位于 `papers/medevolve.md`，对应中文 LaTeX 位于 `papers/medevolve.tex`，英文稿在中文核对后编写。研究主体为纵向医疗记录中的证据支撑任务生成与生成策略更新，下游经验学习作为任务来源价值的验证。

## 正文骨架

1. 引言与相关工作：病例数据的差异如何决定提问方向、已有任务生成机制的医疗适配，以及双探索和策略自进化两项贡献。
2. 问题定义与方法：任务及策略表示、双探索、生成与核验、患者级反馈、策略自进化及采样协议。
3. 实验设置：患者划分、模型、六种方法、指标、公共评价与统计口径。
4. 结果与分析：生成主比较、四轮策略自进化、四组组件消融及下游学习。
5. 讨论与结论：解释范围、结论和独立局限性部分。

## 科学约束

正式结果空值保留，不依据局部运行或协议配置推断实验收益。统计与案例的实施状态分别记录。独立评测固定初始方向配比，策略比较解释为固定方向条件下的生成指导比较。任务生成限定只读，当前公共生成接口要求时间视角字段为空。文献来源和实现位置记录在独立证据文件中，作者核验状态不由自动检查替代。

# 公共实验入口实施任务

## 目标与文件归属

接入五个任务生成方法，使六种方法共用环境和公共评测。负责 experiments/、configs/ 及需要统一调整的 contracts.py；各方法实现由对应 section 负责。

## 依赖

以 common/SPEC.md 为接口依据。先冻结生成入口及共享 TaskBatch 字段，再派发方法实现。实现各 section 使用独立 worktree，修改范围不重叠。

## 实施步骤

1. 将实验入口中仅支持 MedEvolve 的分派改为显式方法映射，保留其探索和迭代流程；其他方法走各自生成入口。
2. 复用公共患者轨迹、任务运行信息附加、评测和保存逻辑，不让方法自行分组患者或另建评测。
3. 配置独立的生成模型预算，固定公共评测模型、解题预算及目标任务数；统一记录生成与评测用量。
4. 对已实现方法做同患者小规模联调，核对失败和少出题也进入汇总。
5. 方法均通过小规模联调后再扩大样本量。

## 最小验收

核对患者边界、解题答案隔离、独立实例释放和方法分派；用同一患者分别跑主方法与一个对比方法。未接入的方法返回明确错误。真实调用只使用已授权的模型。

## 交付

可运行配置、实现提交和真实小样本输出目录。接口变更集中在本 section，同步给方法 section 后才能合并；不增加通用插件框架或独立评测系统。

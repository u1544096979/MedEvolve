# 实验入口实施计划

## 模块职责

管理患者分组、缓存、轮次、产物与结果汇总。

文件归属：experiments/、configs/。共享结构引用根目录 contracts.py。

## 接口

run_experiment、summarize_run。签名与数据结构见[主 specification](../design.md)第 5 节。

## 实施任务

整理轨迹并运行初始探索；逐轮出题、评测、反馈、更新；固定策略评测保留患者；保存文件并汇总。

实施使用独立 worktree；模型与环境配置来自实验配置。其他模块保持各自文件归属。

## 关键验收

两位进化患者、一位评测患者跑两轮；确认患者边界、策略传递、实例释放和文件汇总。

不为字段映射、JSON 往返和简单转发函数单独建立测试。公共闭环覆盖模块之间的调用关系。

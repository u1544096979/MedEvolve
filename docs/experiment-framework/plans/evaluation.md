# 公共评测实施计划

## 模块职责

核验任务证据；评价质量；固定 Agent 解题；判断任务完成情况。

文件归属：evaluation/。共享结构引用根目录 contracts.py。

## 接口

evaluate_task。签名与数据结构见[主 specification](../design.md)第 5 节。

## 实施任务

评审读取轨迹与参考答案；解题只接收题目、患者和工具；写入任务检查实际状态。

实施使用独立 worktree；模型与环境配置来自实验配置。其他模块保持各自文件归属。

## 关键验收

确认解题输入没有答案或缓存轨迹；故障不作为临床失败；写入以状态为依据。

不为字段映射、JSON 往返和简单转发函数单独建立测试。公共闭环覆盖模块之间的调用关系。

# 随机四分之一进化集

## 患者划分

每个环境按真实患者名单排序后，使用随机种子42打乱。25%患者用于进化，剩余患者用于独立公共评测。PhysicianBench为108位，进化27位、评测81位。MedAgentBench以官方100位病历患者为范围，进化25位、评测75位；FHIR服务器中只有Patient来源的额外记录不进入实验。进化集分为互不重叠的两轮，人数分别为13/14与12/13。两个生成模型及六种方法共享患者划分。

## 策略与反馈

MedEvolve每轮生成、评测后更新策略，两轮结束冻结策略。扩大患者数后，反馈输入按患者分开处理并汇总发现，避免所有长轨迹进入一次请求；每个请求保留该任务引用证据并遵守模型上下文预算，所有调用用量与失败保留。矩阵只冻结两轮反馈与更新均成功的策略，反馈或更新失败的进化不计为完成。两轮名单通过cohort的round_patients传递；未提供该字段的历史cohort仍沿用旧行为。

## 运行隔离与复用

新协议使用独立cohort目录与产物根目录。历史产物保留。其他方法仅复用新评测名单中的已完成患者产物，不复用主方法旧策略；无法完整复用的患者继续生成。解题、双裁判与并发协议保持既定配置。旧进化患者必须落在新进化集，防止已通过历史探索暴露的患者进入独立评测集；在符合这一约束的候选随机划分中选择可复现随机结果。

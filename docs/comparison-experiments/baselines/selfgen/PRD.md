# SelfGen 实施任务

## 目标与依赖

实现 SPEC.md 定义的自生成与自答一致性方向。依赖公共实验 section 提供共享生成入口、输出约束、运行结果汇总和预算约定。公共配置与分派由公共实验 section 集成，本 section 负责 methods/selfgen/ 及必要的方法测试。

## 实施步骤

1. 在 methods/selfgen/ 实现公共入口，固定材料组织方式；首轮直接使用公共患者轨迹，不新增摘要模型或摘要服务。
2. 用 runtime.models['generator'] 生成候选，并对每题发起两次彼此独立的自答。
3. 用同一模型进行一致性比较，返回明确的保留判定与依据；候选答案不进入自答输入。
4. 不一致候选筛除；模型故障按运行失败记录，不自动重采样直至一致。
5. 汇总所有生成、自答和一致性检查调用，用一个患者通过公共入口验证。

## 最小验收

每题两份自答上下文相互独立且看不到候选答案；不一致候选不输出。自答一致性与公共证据核验分开记录。 验证关键机制和一个真实患者即可，不为字段转发或提示词字符串建立重复测试。

## 交付

实现提交、所需配置项、小样本任务和公共评测结果。真实调用使用已经授权的 gpt-4o-mini；对方法内部判定、公共核验和生成成本分别记录。接口冲突交给公共实验 section 处理。

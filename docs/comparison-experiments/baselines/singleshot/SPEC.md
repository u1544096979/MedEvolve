# SingleShot 方法对比规范

## 定义

SingleShot 为本实验的“单次生成”方向对比，按本文件定义实现，不对应某篇已确认的论文，也不以论文复现名义报告。没有 MedEvolve 特有的数据探索和跨轮进化。

## 流程

每个患者一次 call_llm，输入同一患者轨迹、两个指定方向及公共输出约束，直接返回最多两道题目、候选参考答案和逐条证据。没有定位、自答复核、环境查询或策略更新。单次生成失败原样返回，不追加修复调用。

## 答案与证据

候选答案与题目在同一次调用中生成。每条患者事实必须能对应轨迹中的 source_id。正确性由独立公共核验判定，方法自身不额外筛选。

## 输入输出

遵循 [公共规范](../../common/SPEC.md) 的 generate_tasks。directions 指定两个目标方向，输出 TaskBatch 最多两题；每题包含 instruction、task_type、reference_answer、evidence 和 decision_point，首轮 decision_point 为 null。患者、环境、方法和任务编号由公共入口附加。

公共输出约束、题型定义与评测提示词一致；方法内部提示词体现上述方向区别。运行状态及成本必须包含全部内部调用，不能只保留最后一份模型结果。

## 文件边界

实现位于 methods/singleshot/。不修改其他方法、公共评测或患者划分。复用标准运行层，不创建自己的 LLM 客户端或 Agent 循环。

# 实验图版式与数据接口

## 范围

图 2 为任务有效性与推理层级的横向百分比堆叠图，图 3 为四维质量的 2×2 均值与区间点图。两图使用相同方法顺序、白底、DejaVu Sans 字体与固定物理尺寸，分别输出 SVG、PDF、PNG。当前交付空白版式与机器可读数据接口，不填入部分实验成绩。方法主图与论文正文由现有文件维护，本任务不修改。

## 图 2

横轴 0–100%，纵轴为 MedEvolve、TaskCraft、Workflow、SingleShot、SelfRefine、EnvExplore。颜色表示核验未通过、评价缺失、上游运行故障及 L1–L4；不同填充纹理提供额外区分。每行附实际生成题数。每个环境与生成模型组合独立出图。

任务只进入一个分类：已有核验未通过结果归入 invalid；核验通过且有难度评分归入对应层级；其余任务因核验或难度评价的运行故障没有评分时归入 runtime_error；剩余任务归入 evaluation_missing。独立解题或完成评审的后续故障不覆盖已有的推理层级。分类计数之和为实际生成题数；生成失败而未形成任务的请求不计入图中分母。

## 图 3

四个面板对应事实准确性、临床合理性、证据充分性、题目清晰度。横轴固定 1–5 分，纵轴方法顺序固定；颜色和标记共同区分方法。点为任务级聚合分数的均值，线为输入数据提供的患者簇 95% bootstrap CI。作图区间不由逐题默认重采样生成。各面板附评分题数与患者数，缺失评分不显示点或区间。

## 接口

输入 JSON 分为 version、groups。每个 group 含 environment、generator、六个方法的 results。每个方法可提供患者数、互斥 outcome 分类计数及四维质量汇总。未知字段使用 null，真实零计数使用 0；缺失区间两端同时为 null。脚本只绘制既有汇总，不推断或补齐缺失结果。

脚本导出 JSON Schema 和空白输入模板；校验方法重复、缺失、非法计数、质量范围、区间顺序与样本量。每组分别导出两张图和同源数据快照。空白模板标注为版式预览，不接入正式论文。

## 实施与验证

1. 建立独立绘图入口、输入模型、统一样式和空白数据模板。
2. 输出两张图的三个格式与数据接口说明。
3. 检查空白输入不产生结果标记；在临时测试中检查计数归一化、区间位置与非法输入拒绝。
4. 检查实际尺寸、PDF 字体、SVG 可编辑文字及 PNG 排版。

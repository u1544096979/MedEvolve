# MedEvolve 方法主图

## 结构

1. 双路探索：进化患者记录与只读工具环境分别形成固定复用的数据知识 K_D 与环境知识 K_E。
2. 任务生成与评估：当前患者轨迹 X_p、探索知识与策略 θ_r 汇入生成器；候选任务包含问题、参考答案与来源证据。原始记录核验通过后，开展质量、推理深度、盲测解题与完成评价。
3. 策略演化：任务评价与失败原因形成反馈 F_r，经归因后更新生成指导 g_r 与题型难度方向权重 w_r，得到下一轮策略 θ_(r+1)。探索知识固定复用，解题设置固定。
4. 独立评测：进化结束后冻结策略，在不重叠的评测患者集生成并评估任务；评测结果不参与策略更新。

## 视觉

横向论文通栏布局，白底，青蓝色知识模块、暖橙色策略演化模块、深灰连线。使用时间轴、记录卡、任务证据卡和策略组成表达语义。英语标签、统一无衬线字体、少量数学符号、清晰箭头与足够留白。

生成器使用青蓝色标题带，探索和评估模块使用浅色标题带，策略模块使用暖橙标题带。任务卡采用轻量叠层，内部字段带独立底色。记录时间轴区分检查、趋势与文本记录；搜索、工具、证据核验、质量、推理、解题、完成与反馈配有语义对应的小图标。图标、色带、卡片和连线均为可编辑矢量元素。

## 布局与导出

患者时间轴紧贴生成器上方，候选任务与评价模块位于同一顶部基线，核验模块与原始记录构成中间列。主流程使用横向连线；策略演化位于下方，返回生成器的连线绕开分区标题。

核验失败与评价结果的反馈连线在模块外汇合，再由一条主线进入反馈归因。策略更新返回生成器的连线使用两个直角转折。

主图由 `papers/figures/make_overview_figure.py` 绘制。运行 `.venv/bin/python papers/figures/make_overview_figure.py` 导出同名 SVG、PDF 和 PNG：`papers/figures/medevolve-overview-v4.*`。SVG 保留可编辑文字，PDF 保留矢量线条与嵌入字体，PNG 提供预览。论文 LaTeX 引用 PDF，Markdown 引用 PNG。

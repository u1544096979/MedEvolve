# 环境能力与患者并行设计

## 1. 环境能力

| 环境 | 查询 | 提交语义 | 数据库变化 |
| --- | --- | --- | --- |
| PhysicianBench | 查询患者记录与关联资源 | 原生工具向 FHIR 服务发送真实 POST | 新增处方、检查或转诊申请、消息、预约等资源 |
| MedAgentBench | 原生 GET 查询患者记录 | POST 解析提交内容并返回接受提示，保留操作记录 | POST 不持久化资源 |

MedAgentBench 的语义对应当前适配的官方提交 `99260117137b09f04837a8c18d18a1107efa55ae`。提交接受提示不能证明数据库发生变化。

环境能力是确定的运行约束。主方法与对比方法接收相同的能力说明，环境探索指导补充实际观察到的工具参数、返回结构与限制，不能覆盖固定能力约束。

PhysicianBench 的写入由 FHIR 服务保存到数据库，不改为独立实验文件。数据库即使采用文件存储，仍由数据库管理其资源与查询语义。实验输出中的请求和执行记录不代替环境状态。

## 2. 任务生成、解题与评测

生成任务必须满足所选环境的实际能力。

- 查询、分析与规划任务可以要求读取既有记录并给出结论。
- MedAgentBench 的操作任务可以要求提交指定请求，明确请求内容与完成条件；不得要求新增资源持久化、查询本次新增资源或执行依赖本次写入结果的后续操作。
- PhysicianBench 可以生成要求真实创建资源的任务，解题在独立环境执行，评测检查实际资源与执行证据。

生成、解题和评测均接收固定环境能力说明。各方法使用相同的能力约束和完成标准，不因方法不同而改变提交或写入的判定。

提交任务检查实际 POST 的目标地址、提交内容和接受结果是否满足题目。格式合法或收到成功提示，不能代替药物、剂量、患者等任务条件的正确性检查。

真实写入任务检查数据库中的实际结果与执行证据。既有资源不能被当作本次操作创建的结果。若 MedAgentBench 生成了要求真实写入的任务，应识别为超出环境能力的任务，不能将其不可完成归因于解题难度。

任务进入解题前明确其是否需要真实写入。仅凭题型或“POST”字样不能确定隔离需求：同一题型可能只要求文字分析，MedAgentBench 的 POST 也不会写入数据库。

## 3. 环境复用与患者并行

### 3.1 共享查询环境

同一环境、同一种子镜像的轨迹读取、证据核验和只读解题复用干净的查询实例。不同环境或不同种子镜像不混用实例。

共享查询实例可以同时服务多个患者，保留现有患者访问边界。查询实例在工具执行入口禁止真实写入，不仅依赖模型遵守题目；意外真实写入不得执行。

MedAgentBench 的模拟提交不会改变数据库，可与查询任务共用实例。各任务的提交记录、执行轨迹和评测结果独立保存。

### 3.2 环境探索

MedAgentBench 的查询与模拟提交探索复用共享实例。

PhysicianBench 的环境探索使用专门的独立种子实例，允许测试原生真实写入。探索完成后释放实例及其独立存储，不将试写后的实例交给查询或解题任务。

### 3.3 真实写入任务

仅当任务要求真实写入且环境具备实际写入能力时，为该任务创建独立种子实例。完成解题和状态读取后释放实例及其独立存储。

不同真实写入任务不复用已被修改的实例，同一患者的不同题目及不同方法均从干净种子开始。共享查询实例不承接真实写入。

### 3.4 并发调度

患者并发数与环境实例并发上限分开配置。五个患者可以并行生成任务，并在共享实例上并行查询或模拟提交；真实写入任务按可用实例额度执行，额度不足时等待。

环境探索的独立实例计入同一实例额度。患者并发不意味着同时启动相同数量的容器，具体并发上限按运行机器资源确定。

同一进化轮内的患者任务使用同一份策略，待本轮任务完成后汇总反馈并更新策略；存在策略依赖的轮次保持顺序。并发不改变既定采样、任务标识与结果归属。

共享实例在使用结束后释放。独立实例在成功、失败或取消时均释放；单任务失败保留所属患者和任务的记录，不将失败实例转为共享实例。

## 4. 验证

1. 确认主方法、已接入对比方法、解题与评测均收到相同的固定环境能力约束。
2. 核对 MedAgentBench 的正确提交、错误提交及要求真实持久化的任务，分别检查正确性判定与环境能力匹配；数据库不应因模拟提交变化。
3. 验证共享实例可以服务并发患者且不能执行真实写入，各患者的数据访问与任务记录保持独立。
4. 验证 PhysicianBench 的试写探索和真实写入任务使用独立种子实例，不污染共享实例或其他任务。
5. 验证患者并发与实例额度分别生效，等待、失败和取消不导致实例泄漏；同轮策略与采样结果保持一致。

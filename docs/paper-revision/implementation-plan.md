# 中文论文核对流程

## 范围

中文正文为 `papers/medevolve.md`，中文 LaTeX 为 `papers/medevolve.tex`。英文 LaTeX 在作者完成中文核对后编写，保留现有图和数据来源。方法以实际实现为依据，正式结果以冻结实验产物为依据。

## 文稿组织

- 引言与相关工作：任务构建问题和方法定位。
- 问题定义与方法：双探索、生成、核验、反馈、采样和策略更新。
- 实验设置：患者划分、模型、比较方法和评价协议。
- 结果与分析：有效产出、四轮策略自进化、四组组件消融与下游学习。
- 讨论、结论及独立局限性部分。

## 核对顺序

1. 作者核对标题、摘要、贡献和方法描述。
2. 按证据索引核验实验配置、来源、主张及尚缺结果。
3. 填入正式实验成绩，完成跨章节数字一致性检查。
4. 中文确认后编写英文 LaTeX，检查 NAACL 篇幅、引用和 PDF 排版。

## 验证边界

参考文献本地检查只检查标识符格式和重复，不替代文献主张核验。正文结构、表格列数、公式分隔、来源文件及行哈希均可本地检查；空结果和未核验声明不能因结构检查通过而视为提交就绪。

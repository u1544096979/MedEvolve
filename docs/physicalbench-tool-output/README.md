# PhysicianBench 工具输出

## 截断规则

每次工具调用返回的正文最多保留 10,000 字符。超出时保留前 10,000 字符，并附加 `… [result truncated]`。

## 返回格式

工具返回序列化后的结果文本。多个工具各自应用同一上限。

不符合患者访问范围的工具请求返回 `error`，不返回患者数据；调用者可修正参数后继续。环境不可用与不支持的时间过滤仍终止运行。

环境探索最终返回 `{"guidance":"抽象环境指导正文"}`，`guidance` 位于对象最外层。

## 验证标准

不超过 10,000 字符的结果完整返回；超出上限的结果截断并附加提示。查询与写入的执行语义保持一致。

越界患者查询与写入不得到达 HTTP 服务；越界关联记录和响应数据不得返回给调用者。拒绝后，允许范围内的查询仍可完成。

# 主方法生成质量实施任务

## 目标与归属

提高任务事实、引用及答案的一致性，减少题型偏离。负责 methods/medevolve/；公共核验调整由公共实验 section 协调，不自行改变 contracts.py 或公共评测口径。

## 实施顺序

1. 依据 main/SPEC.md 对齐事实查询与临床判断的候选答案样例，确认每条证据如何支持声明和结论。
2. 调整生成材料，保留事件与来源 ID 的直接对应，避免只给零散 ID 而让模型重新猜测记录来源。
3. 调整生成提示词，在一次调用中落实事实选取、题目与答案构造、逐条引用；使用本次指定的题型，避免全题型列表干扰。
4. 同患者少量复测，保留被公共核验拒绝的候选与理由，检查是否仍存在错药物、错数值和错日期。
5. 重跑两轮闭环，确认反馈基于可靠评测结果，评测患者能正常出题。

## 最小验收

核对正确引用通过、错误引用被拒绝，以及临床合理等价方案可接受。检查题型属于本次方向、参考答案不进入解题输入、运行故障不作为难度提升。真实效果以产出和评测结果为依据，不用仅有本地测试通过代替。

## 交付

方法提交、小样本候选与评测产物、两轮运行结果。保留单次生成形态；临床答案判定存在争议时先给出具体题目、记录与判定，完成口径对齐后再改规则。

# 策略自进化示例图

## 内容

图置于中文论文 2.4 节末尾，以“初始指导 → 核验反馈 → 更新后指导”三个阶段展示一次生成指导变化。实例来自 PhysicianBench 进化记录，图中使用概括后的规则，不包含患者标识、日期、检查值或个体诊疗信息。

初始指导：关联病程节点，判断治疗变化。
核验反馈：缺少随访结果，疗效判断证据不足。
更新后指导：核对基线与随访，确认数据可比性，证据不足时限定结论。

该图描述反馈如何转化为规则，不表示任务重新生成后已经通过核验或取得成绩提升。

## 排版

纵向三阶段，按论文单栏宽度排版。英文文字、白底、青蓝与暖橙配色、深蓝箭头，与方法主图的字体和细线圆角边框一致。文档、文档检索与齿轮图标分别对应初始指导、核验反馈与更新后指导。两个箭头标注 Evaluate 和 Revise。图注由正文承担。输出位于 `papers/figures/medevolve-strategy-example-en.png`，生成提示位于 `prompt-icons-en.txt`。

## 来源与生成

依据 `outputs/physicianbench-evolution-comparison-20261005-234810/run/rounds/0001/` 下的 `strategy.json`、`feedback.json` 和 `next_strategy.json`。图中文字为规则概括，原始来源留在本地。发送给生图工具的内容仅为通用规则及版式要求，不含论文全文、原始病历或反馈中的个体信息。

采用项目 paper-illustration 的版式检查要求，渲染使用内置 image_gen。当前不执行该技能的 Gemini/Claude 多模型调用流程。

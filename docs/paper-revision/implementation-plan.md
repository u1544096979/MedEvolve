# 论文整理实施计划

**目标：** 在现有论文中完善实验协议和展示框架，同步 Markdown、LaTeX 与 PDF。

**组织：** 保留章节主干，以现有实现、NUC 协议和官方 Benchmark 设计校正事实。正式结果保持空值，未执行的补充分析只定义评估设计。

**工具：** Markdown、LaTeX、XeLaTeX、Poppler。

## 约束

- 不修改实验代码、配置或运行状态。
- 不将部分结果写成完整实验结论。
- 不新增插图；保留当前总览图，确定其余图的图注与位置。
- 不把共享患者的任务级划分描述为未见患者泛化。
- 不把单次训练的样本置信区间描述为跨训练稳定性。

## 任务 1：正文事实与叙述

- [ ] 校正双探索、单次生成、反馈归因、方向采样及预算描述。
- [ ] 压缩重复论述，保留方法主线与必要公式。
- [ ] 核对基线名单、裁判数量、患者划分与经验训练边界。

## 任务 2：实验与附录

- [ ] 完善实验 1 设置、分母、分布与成本报告，建立空结果表。
- [ ] 完善实验 2 训练、官方共同测试与辅助合成测试，建立空结果表。
- [ ] 定义消融、初始与最终策略比较、人工审查、成本和案例框架。
- [ ] 整理评分标准、聚合公式、数据划分和 Harness 细节，消除重复附录编号。

## 任务 3：同步与排版

- [ ] 同步 LaTeX 正文、公式、表格和图注。
- [ ] 编译 PDF，检查排版告警并逐页检查正文和表格。
- [ ] 核对 Markdown 与 PDF 的标题、表图、文本和空结果标记。
- [ ] 将仅涉及论文和本目录的提交合并回原分支。

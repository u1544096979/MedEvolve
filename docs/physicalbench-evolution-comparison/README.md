# PhysicianBench 策略进化对照实验

## 患者划分

108 名患者按固定随机种子 42 打乱，65 名用于训练、43 名用于测试，两组不重叠。小批量从各组选择可在生成模型输入上限内完整读取的患者：3 名训练、2 名测试。小批量结论仅适用于该样本。

## 训练与生产

仅训练患者参与数据探索、环境探索、两轮任务生成、公共评测、反馈和策略更新。每轮每名患者最多生成两题。测试患者使用冻结策略生成任务，其评测结果不进入反馈或策略更新。

## 前后对照

同一次实验共享训练集探索指导。初始策略与最终策略在同一测试患者上分别生成最多两题，使用固定随机种子和初始题型配比安排相同生成方向。生成模型为 gpt-4o-mini，探索、反馈、策略更新及公共评测使用 DeepSeek V4.1 Flash。各次环境独立，本机串行运行单个 4 GB Docker 容器。

## 结果

分别保存初始策略测试、训练轮次和最终策略测试的任务、评测及调用记录。报告生成数量、核验通过率、四维质量判断、解题完成情况与 token 成本。少量样本的差异不作为稳定进化收益结论。

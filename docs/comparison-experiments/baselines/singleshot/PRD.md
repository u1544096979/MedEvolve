# SingleShot 实施任务

## 目标与依赖

实现 SPEC.md 定义的单次生成方向。依赖公共实验 section 提供共享生成入口、输出约束、运行结果汇总和预算约定。公共配置与分派由公共实验 section 集成，本 section 负责 methods/singleshot/ 及必要的方法测试。

## 实施步骤

1. 在 methods/singleshot/ 实现公共 generate_tasks 入口，使用 runtime.models['generator']。
2. 组织完整患者轨迹及可定位的来源记录，使用公共题型、证据和输出约束，省略主方法的探索指导及进化策略。
3. 一次调用返回 TaskBatch；记录该调用的 trace、usage 和错误，不补题或重试。
4. 通过公共入口运行一个患者，核对生成调用只有一次，核验与解题调用另行统计。

## 最小验收

单次调用只发生一次；没有携带主方法指导、策略或评测答案。输出遵循指定方向；证据不足允许空批次。 验证关键机制和一个真实患者即可，不为字段转发或提示词字符串建立重复测试。

## 交付

实现提交、所需配置项、小样本任务和公共评测结果。真实调用使用已经授权的 gpt-4o-mini；对方法内部判定、公共核验和生成成本分别记录。接口冲突交给公共实验 section 处理。

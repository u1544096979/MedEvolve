# SelfGen 方法对比规范

## 定义

SelfGen 为本实验的“自生成与自答一致性”方向对比，按本文件定义实现，不对应某篇已确认的论文，也不以论文复现名义报告。没有 MedEvolve 特有的数据探索和跨轮进化。

## 流程

输入由同一患者轨迹固定组织的文本材料，先一次调用生成最多两道题、候选参考答案及证据。随后对每道候选题进行两次独立自答，形成包含首次候选答案在内的三份答案。自答只接收题目及同一份患者材料，不接收候选答案或其他自答结果。每题再一次调用比较三份答案的一致性，保留一致题。该流程没有环境工具、数据探索或跨轮策略更新。

## 答案与证据

参考答案保留首次生成的候选答案，不用后一份自答覆盖。比较以临床含义和事实为准，不能用字符串相等代替语义一致。三份答案一致只说明自答一致性，不证明其受原始数据支持；公共核验继续执行。

## 输入输出

遵循 [公共规范](../../common/SPEC.md) 的 generate_tasks。directions 指定两个目标方向，输出 TaskBatch 最多两题；每题包含 instruction、task_type、reference_answer、evidence 和 decision_point，首轮 decision_point 为 null。患者、环境、方法和任务编号由公共入口附加。

公共输出约束、题型定义与评测提示词一致；方法内部提示词体现上述方向区别。运行状态及成本必须包含全部内部调用，不能只保留最后一份模型结果。

## 文件边界

实现位于 methods/selfgen/。不修改其他方法、公共评测或患者划分。复用标准运行层，不创建自己的 LLM 客户端或 Agent 循环。

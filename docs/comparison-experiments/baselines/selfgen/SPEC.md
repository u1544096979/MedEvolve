# SelfRefine 方法对比规范

## 方法定义

SelfRefine 是基于自反馈的单患者任务迭代修订方法：生成初稿，由同一模型批评当前任务，再根据反馈修订题目、候选参考答案和证据。算法参考 [Self-Refine: Iterative Refinement with Self-Feedback](https://arxiv.org/abs/2303.17651) 的反馈与修订机制，医疗任务生成属于本项目适配，不宣称原论文实验复现。

展示名称为 SelfRefine；配置 method、实验分派及 source_method 保留 selfgen，实现目录为 methods/selfgen/。与主方法对齐患者事实、引用、临床答案和公共评测约束。反馈仅作用于当前患者批次，不使用主方法的数据探索指导、环境探索指导、进化策略或公共评测反馈，不跨患者积累经验。

## 输入输出与患者边界

沿用 [公共规范](../../common/SPEC.md) 的契约：

```python
async def generate_tasks(
    trajectory: PatientTrajectory,
    environment: EnvironmentConfig,
    directions: list[GenerationDirection],
    runtime: RuntimeConfig,
) -> RunResult: ...
```

trajectory.environment 与 environment.name 必须一致，directions 必须包含两个生成位置。生成、自评及修订读取同一患者的公共轨迹正文及 sources 中的原始来源记录，不另建摘要服务，不从其他患者补充事实。输入材料是数据，不能改变角色指令或输出约束。

任务类型沿用现有五类：诊断与解释、检查与风险分层、治疗规划、药物处方、治疗重规划。公共实验入口沿用现有题型与难度采样规则，为当前患者提供两个 directions；两个位置可以属于相同或不同题型，数量按实际指定方向限制。方法依据患者轨迹和这两个方向生成题目，不自行重新采样，不固定为某一类任务，也不要求每个患者覆盖全部五类。

最终输出 TaskBatch，最多两题；证据不足允许少出题或空批次。每题包含 instruction、task_type、reference_answer、evidence、decision_point。题型、数量及难度遵循两个指定方向，修订不能改变所属方向或增加生成位置。两个环境的 decision_point 均为 null。患者、环境、轮次、方法及任务编号由公共入口附加。

## 生成、自评与修订

每批一次调用生成初稿，随后最多三次自评，采用通过即停。当前批次全部题目通过后立即结束，不为凑满三次继续检查。自评针对整个当前批次，一次返回逐题判断；上限按批次计算，不将多份答案一致性作为通过条件。

| 阶段 | 后续处理 |
| --- | --- |
| 初稿生成 | 空批次结束；非空进入第一次自评 |
| 第一次自评 | 全部通过则结束；否则修订一次后进入第二次自评 |
| 第二次自评 | 全部通过则结束；否则修订一次后进入第三次自评 |
| 第三次自评 | 保留通过题目，筛除仍不通过题目，结束批次 |

自评输入包含患者原始材料、指定方向及当前完整候选。逐题检查题意明确性、题型与难度匹配、临床价值、答案回应性、患者事实准确性和证据覆盖。反馈指出有问题的题干、答案内容或引用，说明问题与可执行的修改要求，不凭空增加患者事实，不仅给抽象评分。

方法私有反馈模型包含 questions 列表；每项为 candidate_index、passed、issues。candidate_index 为当前批次的零起始索引，每道候选恰好一项，禁止重复、缺失及越界。issues 为文本问题列表，通过时为空，不通过时必须非空。反馈矛盾或结构无效按模型输出故障记录，不追加格式修复调用。

修订输入包含同一患者材料、指定方向、当前候选及本次反馈，一次返回修订后的 TaskBatch。通过题目保持原样；仅修订不通过题目的题干、答案及证据，无法依据材料修正时可删除。方法内部保留候选与原始方向位置的关联，删题或顺序变化不能导致方向错配。修订为空批次时结束，不补题、不重新采样。

修订后的非空任务必须接受下一次自评。第三次之后不再修订，不输出未经自评的版本。最终参考答案及证据取最后一次自评通过的当前版本，历史版本保存在 trace 中。

## 事实、答案与证据

遵循 [主方法规范](../../main/SPEC.md) 及 [生成输入与答案约束](../../main/GENERATION.md) 的事实与引用规则。先选择真实事实，再组织题目、答案及引用；source_id 必须属于当前患者输入来源集合，每条 statement 只陈述对应原始记录支持的事实。候选答案的全部患者事实需有引用覆盖，跨记录推断分别引用依据。

事实查询给出记录支持的数值、单位及事件时间，不用资源更新时间替代临床事件时间。药物片剂规格与实际给药剂量分别表述；活动处方不证明实际服用、疗效或耐受性。轨迹未记载某事实不能证明其不存在。

临床判断区分患者事实、合理推断和材料限制，允许有依据的等价方案，不将真实后续治疗作为唯一正确答案。难度来自信息整合及临床判断，不来自歧义、事实缺失或环境故障。非空题目必须有非空题干、候选答案及证据。

## 两个环境的支持要求

| 项目 | PhysicianBench | MedAgentBench |
| --- | --- | --- |
| 患者材料 | 公共 prepare_trajectory 与 FHIR 原始来源 | 公共 prepare_trajectory 与现有 snapshot 回退 |
| 生成、自评、修订 | 公共 call_llm，无工具 | 公共 call_llm，无工具 |
| 证据核验 | 公共 read_evidence | 公共 read_evidence |
| 独立解题 | 公共 run_agent 与原生 FHIR FunctionTool | 公共 run_agent 与 NativeTools 的 GET / POST / FINISH |
| 操作判定 | 实际返回与持久化状态 | POST 接受请求不证明数据库写入 |
| 决策点 | null | null |

复用现有公共环境适配，不建立方法专属环境客户端或工具 Agent。生成、自评及修订不访问工具或执行写入；环境名称决定公共适配与操作约束，不改变反馈修订算法。

操作任务明确表达环境实际支持的要求。MedAgentBench 的提交任务按原生协议及执行记录判定，不要求新增数据库记录证明提交成功；PhysicianBench 的持久化任务按实际状态判断。不能以空查询、运行故障或其他实例试写记录补充患者事实。

## 公共评测与答案隔离

自评只决定候选是否修订或输出，不能代替独立公共核验。最终任务统一进入 evaluate_task，执行逐条证据核验、题目与答案支持性核验、四维质量评价、独立解题及完成评价。公共层不按 source_method 改变判定标准。

固定解题 Agent 仅收到题目、患者、决策点及对应环境工具，不接收候选答案、证据、自评反馈或修订历史。公共评测结果不回流生成循环，不改变后续患者策略。自评通过不等于事实正确，也不等于人工金标准。

## 模型、预算与运行记录

内部阶段统一使用 runtime.models["generator"]，角色配置与同环境主方法对齐，不固定模型名称；预算来自 runtime.budgets["generator"]，按患者批次累计。最多一次初稿、三次自评、两次修订，共六次模型调用，工具调用为零。外部预算不足时优先停止，不能额外增加预算或隐藏内部调用。

初稿、自评或修订发生模型故障、结构故障或预算耗尽时停止本批，RunResult 保留 failed 或 budget_exhausted 及错误，output 为 null。未完成必要自评的候选不能作为成功任务输出。正常达到第三次上限时，筛除失败题目，返回 completed 和剩余 TaskBatch；全部筛除返回空批次。

trace 按 candidate_generation、self_review/1..3、refine/1..2 及最终筛选记录保存原始输入输出、逐题反馈、版本和拒绝原因。usage 累计 model_turns、tool_calls、input_tokens、output_tokens、total_tokens，包含失败尝试；筛选记录不计额外模型调用。生成与公共评测成本分开汇总，报告实际题数、有效题数和有效题成本。

## 实现与验收边界

方法实现及私有反馈模型位于 methods/selfgen/，机制测试位于 tests/method/。公共入口负责分派、方向采样、元数据、双环境配置及汇总，必要公共接入由公共实验 section 集成。复用 contracts、GenerationBudget、公共输出约束、运行层及评测，不改变其他方法算法或主方法行为。

验收覆盖提前结束、两次修订后第三次判定、部分保留、空批次、结构故障、预算耗尽、全部成本、答案隔离及两环境操作语义。两个环境分别完成至少一名真实评测患者的生成与公共评价；少出题、核验拒绝和故障按实际记录。实施步骤见 [PLAN.md](PLAN.md)。

| 验收编号 | 要求 |
| --- | --- |
| A1 生成依据 | 五类题型及公共采样不变，读取当前患者材料和两个指定方向，修订保持题型与难度 |
| A2 循环与版本 | 通过即停，最多三次自评、两次修订、六次调用，通过题不改，最终输出已自评版本 |
| A3 故障与成本 | 模型或结构故障、预算耗尽终止批次，output 为 null，全部尝试进入 trace 和用量 |
| A4 公共评价 | 公共核验独立，答案与反馈不进入解题输入，公共评价不回流修订或后续患者 |
| A5 双环境 | 同一算法支持 PhysicianBench 和 MedAgentBench，保留各自操作语义，分别完成真实验收 |

# 论文整理方案

## 范围

在 `papers/medevolve.md` 与 `papers/medevolve.tex` 上修改，保留摘要、引言、相关工作与问题定义、方法、实验、讨论与结论、附录的主干。实验结果表保留空值，不将运行中的部分成绩作为正式结果。

## 正文结构

方法按数据与环境探索、知识引导生成、反馈与策略更新展开。实验 1 明确患者划分、六种生成方法、核验、质量、推理要求、有效产出与成本。实验 2 明确四种 Harness 的经验学习、官方任务上的共同测试和来源内部合成测试。补充实验在现有分析小节中组织消融、固定患者上的策略比较、人工审查与成本。

## 表图

实验 1 的数量与有效性、四维质量、推理要求分别成表，结果使用破折号。实验 2 按环境与 Harness 给出来源之间的官方任务成绩及百分点提升。分布图、提升图与案例图只确定图注和承载的信息，不生成模拟数据或新插图。

## 事实与验证

实现与运行协议为方法描述的依据。质量与难度的正式实验采用 GPT-5.4-nano 与 GPT-4o-mini 两模型裁判，整数中位数聚合；核验失败材料可进入缺陷反馈。生成采用单次调用，读取按上下文预算选取的轨迹材料。经验训练与任务生成侧策略进化分开描述，患者级划分与任务级划分分开报告。

两份正文的段落、公式和表格保持一致。使用现有 LaTeX 模板编译并检查 PDF 中的表格、公式、图注和章节衔接。改动仅涉及论文及本目录文件。

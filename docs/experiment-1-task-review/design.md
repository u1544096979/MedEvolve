# 实验一题目抽样审查

## 样本范围

从 NUC 实验一正式 MedEvolve 独立评测批次中，对 verification.valid=true 的题目进行简单随机抽样，样本量 30，固定种子 20261009。纳入两个生成模型、两个环境的正式 MedEvolve 重试批次，排除进化、烟测、历史对照与未选定尝试。抽样要求事实核验通过，不要求解题成功；分别报告生成、核验通过与解题成功数量。

## 逐题审查

每题使用 CC Switch 中 PI 的 clinepass 源，模型 cline-pass/deepseek-v4.1-flash，独立审查一次；接口失败或输出截断时允许重试，保留每次调用记录与用量。输入包含题干、参考答案、引用声明及原始资源；原始资源来自已有核验请求记录及轨迹缓存。病历上下文沿用已保存的评测请求材料，超长病历的裁剪状态单列；全部引用资源独立完整提供。审查证据一致性、问题可回答性、答案正确性、歧义、任务类型与格式。裁判先独立判断题目，再依据原解题记录分析失败原因。

## 难度与设计缺陷

分别标记合理难度、证据不足、参考答案问题、题干问题、评分问题和运行问题。无法从提供资料判定的内容标记不确定，不以未解答推定高难度，也不以既有裁判结果代替独立判断。

## 分类统计与典型案例

保存抽样清单、逐题原始响应、模型用量和统计。比例以审查成功的样本为分母，问题类别允许多选。统计只描述抽样结果；方法分组仅作样本描述。报告包含代表案例与题目定位信息。

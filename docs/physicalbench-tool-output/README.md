# PhysicianBench 工具输出

## 返回格式与长度上限

工具返回序列化后的紧凑 JSON 文本（`separators=(",", ":")`、`ensure_ascii=False`）。`environment.tool_result_limit` 控制每次返回的字符上限，包含 JSON 结构、记录与裁剪标记；默认值 10000，现有环境探索配置使用 5000，配置下限 256。低于下限时在创建工具前报配置错误。多个工具各自应用同一上限。

## 裁剪规则

未超限的结果原样返回，结构与内容不变。超出上限时按完整记录选择：不删除记录内字段、不截断字符串、不在 JSON 末尾追加文本。裁剪后的查询结果保留 `entries` 和能够容纳的原有结果信息，并附加 `truncation` 对象：

- `truncated`：是否因返回长度上限裁剪。
- `total_records`：本次工具实际取得的记录数，不替代服务返回的 `total`。
- `returned_records`：本次交付的完整记录数。
- `message`：结果未完整交付的提示。

第一条记录已超限时返回空 `entries`，`message` 提示单条记录超过上限、需要缩小查询范围。

非记录列表结果超限时返回结构化超限提示 `{"status":"response_omitted","truncation":{...}}`，不返回部分资源。写入响应超限时返回 `{"status":"succeeded","truncation":{...}}`，保留操作成功的事实并提示不要重复写入。

返回长度限制只约束交付内容，不改变工具执行结果。

## 错误返回

不符合患者访问范围的工具请求返回 `error`，不返回患者数据；调用者可修正参数后继续。错误返回同样受限：超限时以固定短提示替换原错误文本，返回合法的结构化 `error` 与 `truncation`，既不硬切字符串，也不声明操作成功。环境不可用与不支持的时间过滤仍终止运行。

环境探索最终返回 `{"guidance":"抽象环境指导正文"}`，`guidance` 位于对象最外层。

## 验证标准

不超过配置上限的结果完整返回；超限结果按完整记录裁剪并附裁剪标记，返回长度不超过上限且可解析为 JSON。单条超大记录、写入响应与超限错误均返回合法 JSON，配置低于下限时在工具调用前拒绝。查询与写入的执行语义保持一致。

越界患者查询与写入不得到达 HTTP 服务；越界关联记录和响应数据不得返回给调用者。拒绝后，允许范围内的查询仍可完成。
